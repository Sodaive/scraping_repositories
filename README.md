# 🔎 Scraping Repository

A lightweight Python tool that fetches and displays all public GitHub repositories of a specified user, along with their star counts.

This project was built as a small practical exercise in **Python, web data extraction, API interaction, and structured data processing**.

---

## ✨ Features

- 🔍 Search repositories by GitHub username
- 📦 Retrieve all public repositories
- ⭐ Display the number of stars for each repository
- 📊 Present repository information in a clean format
- 🐍 Built entirely with Python
- ⚡ Simple and lightweight
- 🧩 Easy to extend for additional repository statistics

---
## Get Starting

First, clone the repo and get the requirements:

```
pip install -r requirements.txt
```
